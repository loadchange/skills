## 1. 通用任务卡

动笔前在内部完成六项，不要把任务卡原样输出：

1. 目标：通知、说服、介绍、吐槽、讲故事、回应或销售。
2. 硬事实：人名、数字、时间、功能、结论和必须保留的词。
3. 受众：朋友、同事、客户、公众、舞台观众或特定角色。
4. 主矛盾：面子与结果、计划与现实、规则与人性、花钱与效果、认真与荒唐。
5. 主物象：选一个钱、饭、门、鞋、车、手机、表格、杯子等具体东西。
6. 风格旋钮：笑度、黑度、时空、舞台感、收束方式。

若主矛盾找不到，先用一句话补全：

“这个人想要____，却因为____，越努力越____。”

若主物象找不到，问：

“这件事最后会落在哪个能看见、摸到、花钱或搬动的东西上？”

## 2. 改写模式

### 2.1 第一遍：剥离原文

把原文拆成三层：

- 不可变：事实、立场、承诺、行动指令。
- 可重排：解释顺序、例子、句长、开头和结尾。
- 可新增：自嘲、生活类比、人物反应、轻度夸张、回调。

不要逐句找同义词。原文越书面，越应先抽取信息骨架，再重新组织。

### 2.2 第二遍：寻找笑点来源

优先从原文本身找，不要外贴段子：

- 它是否有自相矛盾？
- 谁在维护面子？
- 谁怕麻烦却把事情弄得更麻烦？
- 哪个术语按字面执行会变得荒唐？
- 哪个物件可以前后两次出现？
- 哪个流程看似专业，实际一直绕回原点？
- 哪个角色说的体面理由和真实动机不一致？

只选最强的一到两个来源。

### 2.3 第三遍：重建口播结构

短改写可按六拍：

1. 直接落地事实。
2. 给出一个正经判断。
3. 追问“为什么”或替听众提出异议。
4. 用生活物象解释。
5. 把逻辑多推半步。
6. 用短句回到原结论。

中长改写可按八拍：

1. 场景和人物。
2. 人物一个小盲点。
3. 第一次正常行动。
4. 第一次意外。
5. 人物用错误办法补救。
6. 代价升级。
7. 主物象回收。
8. 完成原文目标。

### 2.4 保真规则

- 数字不可为了押包袱随意改变。
- 产品能力不可夸大。
- 引用不可变成虚构来源。
- 道歉不可变成甩锅。
- 通知的时间、地点和动作必须一眼可见。
- 原文若已有幽默，优先增强节奏和回调，不重复解释。

### 2.5 改写后的删改

删掉：

- 与用户目标无关的历史岔话。
- 第二个主物象。
- 连续出现的舞台称呼。
- 没有行动后果的谐音。
- 为了押韵而牺牲准确性的句子。

保留：

- 一处具体场景。
- 一处人物盲点。
- 一处有效落差。
- 一处完整回扣。

## 3. 背景创作模式

### 3.1 先发明一个可反噬的欲望

从背景中选择最普通、最容易过量的欲望：

- 想省钱。
- 想显得专业。
- 想一次解决所有问题。
- 想让别人羡慕。
- 想偷懒但不愿承认。
- 想严格按规矩办。
- 想证明自己胆大。

欲望要让人理解，过量后才好笑。

### 3.2 再选择结构

生活吐槽：

小目标 → 一个聪明办法 → 办法制造更大麻烦 → 主物象回收。

职场段落：

正经任务 → 体面术语 → 真实执行 → 多推一步 → 短判词。

人物小传：

地点与身份 → 名字或绰号 → 表面长处 → 真正盲点 → 一件事证明。

民间故事：

时间、地点、人物 → 欲望 → 规则异常 → 三次加码 → 因果反噬。

怪谈：

日常场景 → 小异样 → 普通解释 → 假安全 → 规则显现 → 信息翻转。

### 3.3 用三次加码时

三次必须各不相同：

1. 外界给他一次提醒。
2. 他因性格主动忽略。
3. 他拿前一次的补救方案继续补救，终于反噬。

不要只是把数字从一变二变三。

### 3.4 设计回调

在开头埋一个：

- 名字。
- 物件。
- 误听。
- 口头承诺。
- 身体小毛病。
- 过度具体的数字。

结尾让它：

- 解决问题。
- 暴露人物。
- 反转意义。
- 变成代价。

回调应让读者感觉“原来前面那句不是闲话”。

### 3.5 默认收尾

优先级：

1. 回调收尾。
2. 人物自己说漏嘴。
3. 一句生活判断，再立刻用小现实拆一下。
4. 完整反转。

除非用户明确要悬念，不用“且听下回分解”或突然断掉。

## 4. 长度配方

### 4.1 80 字以内

- 不用完整说书开场。
- 一个物象。
- 一个逻辑转向。
- 一句落槌。

### 4.2 80–200 字

- 一句场景。
- 一次自问自答。
- 一个生活类比。
- 一个回扣。

### 4.3 200–500 字

- 人物一个盲点。
- 两次行动或一次小递进。
- 两种包袱机制以内。
- 至少一处前后呼应。

### 4.4 500–1200 字

- 时间、地点、人物交代清楚。
- 三次加码。
- 一段有功能的岔笔。
- 角色语气可区分。
- 至少两个伏笔得到回收。

### 4.5 1200 字以上

先在内部列“伏笔台账”：

- 物件何时出现、何时换义。
- 人物欲望如何升级。
- 哪次岔笔为后文付款。
- 何时降低笑点密度。
- 结尾解决哪些承诺。

长篇每 400–700 字安排一次阶段回报，不能只许诺最后一个大包袱。

## 5. 场景调档

### 5.1 商务通知

- 笑度设轻。
- 先把时间、动作、负责人写清楚。
- 用一个流程或物象类比。
- 不写古代地名、鬼怪和黑色幽默。
- 结尾保留明确行动指令。

### 5.2 营销文案

- 保留真实卖点和限制条件。
- 让笑点来自用户痛点，不来自虚假功效。
- 可用“错误办法越补越麻烦”，再让产品自然解决。
- 不冒充名人代言或真实引用。

### 5.3 社交吐槽

- 可提高舞台感和自嘲。
- 先笑自己参与其中，再笑荒谬现象。
- 避免真实个人隐私、外貌和不可改变特征。

### 5.4 知识解释

- 准确性优先。
- 用一个生活物象解释概念。
- 笑点放在误区或错误推理上。
- 不用未经核实的历史轶事。

### 5.5 道歉、哀伤、医疗、法律与事故

- 默认笑度为零或极轻。
- 不拿伤害、病痛、死亡、受害者或责任开玩笑。
- 若用户确实要缓和语气，只使用自嘲、生活化和温和回扣。
- 不让风格削弱责任、风险或行动建议。

### 5.6 古风与怪谈

- 增加空间、动作和规则细节。
- 允许少量评书套语。
- 现代词只用于一次精准解释。
- 先认真营造氛围，再用日常琐事泄压。
- 最后用规则或信息翻转，不靠乱码式故弄玄虚。

### 5.7 黑色讽刺

- 从小利、小错或一句闲话起步。
- 让每个人都按自己的利益做“合理”选择。
- 让解决方案制造下一层问题。
- 笑制度逻辑和人物自利，不细写受害者痛苦。
- 结尾回收最早的小物件或小决定。

## 6. 原创示例

以下例子只展示结构，不是固定模板。

### 6.1 书面原文改写

原意：

“项目需求多次调整，导致团队返工。希望以后先确认目标，再开始开发。”

风格化完成稿：

“这项目按说不复杂，先把目标定了，再开工。可我们这边有个讲究：第一天要简洁，第二天要丰富，第三天要求简洁地丰富。您听着像四个字，开发听着像四个月。团队前前后后改了五版，最后大家一致认为，还是第一版最接近初心。人干活不怕方向远，就怕方向坐旋转木马，看着挺热闹，一步没离开原地。所以下回先把目标钉住，再动手，省得代码没长大，版本号先儿孙满堂。”

机制：

- 体面术语落到执行成本。
- “简洁地丰富”制造矛盾。
- 旋转木马作为主物象。
- 版本号在结尾回收返工。

### 6.2 只有背景

背景：

“朋友买了昂贵的智能猫砂盆，猫却坚持去花盆里上厕所。”

完成稿：

“我有个朋友，花小一万买了个智能猫砂盆。能称重，能除味，能联网，猫进去一趟，手机上连日报都给你出了。设备到了，他郑重其事摆在客厅，猫过来闻了闻，扭头上花盆里办事去了。朋友不服，又换猫砂、调灯光、升级固件，折腾得那盆比他自己体检还勤。第三天机器终于推送一条消息：连续七十二小时未检测到宠物。花盆那边倒长势喜人。你看科技这东西多好，什么都能统计，就是管不了客户往哪儿办公。”

机制：

- 把宠物设备写成办公系统。
- 三次补救逐步加码。
- “日报、办公”形成前后语域统一。
- 花盆在结尾回收。

### 6.3 轻度知识解释

主题：

“为什么备份不能只放在同一台电脑？”

完成稿：

“备份这件事，怕的不是你没复制，怕的是你复制得太团结。原文件在桌面，副本在 D 盘，俩人住一台电脑里，平时互相照应；硬盘真坏了，走的时候也是一家一块儿走。稳妥的办法是至少再放一份到另一台设备或可信云端。备份讲究的不是兄弟多，是别住一个院儿。”

机制：

- 抽象风险落到“住一个院儿”。
- 轻自问式判断。
- 不改技术结论。

## 7. 评分与返工

每项 0–2 分：

### 7.1 任务完成度

- 0：目标被幽默遮住。
- 1：目标可辨，但行动或重点不够清楚。
- 2：一眼能看出用户要表达什么。

### 7.2 事实保真

- 0：改了事实、数字或立场。
- 1：事实基本在，但有模糊或夸大。
- 2：硬事实完整准确。

### 7.3 因果与人物

- 0：随机梗拼贴。
- 1：有场景，但转折牵强。
- 2：笑点由人物欲望、规则或前文细节自然发生。

### 7.4 口语与节奏

- 0：书面僵硬或碎成病句。
- 1：大体顺口，但包袱没有停顿。
- 2：意群清楚，长短有变，朗读自然。

### 7.5 幽默质量

- 0：靠口头禅、粗俗或强行谐音。
- 1：有一处好笑，但无回扣。
- 2：铺垫、歪半步、落槌和回收完整。

### 7.6 原创与适配

- 0：像现成段子或冒充本人。
- 1：原创但场合、黑度或舞台感不合适。
- 2：表达原创，且适合受众与场景。

总分低于 10 分就返工。优先返工顺序：

1. 恢复事实和任务目标。
2. 重选主矛盾与主物象。
3. 删除无功能口头禅。
4. 补人物行动和因果。
5. 最后才润色方言和节奏。

出现以下任一项直接返工，不看总分：

- 冒充真人发言或背书。
- 复制源语料独特句段。
- 改动关键事实。
- 拿受害者或弱者痛苦取乐。
- 使用转写错字和乱码营造风格。
- 用户要完整文案，却故意悬断。

## 8. 原创性与归属检查

完成稿发布前问：

- 是否出现一眼可识别的经典段子结构或标志句？
- 是否固定加入真实人物，仿佛来自原场次？
- 是否连续复用来源文本的独特短语？
- 是否让读者误以为这是郭德纲真实说过的话？

若答案为“是”：

1. 保留事实和笑点功能。
2. 更换物象、比喻、场景和句法。
3. 删除真实人物与场次信息。
4. 改成明确的原创京味说书式表达。

风格应体现在因果、节奏、人物和落差中，而不是可追溯的句子表面。
